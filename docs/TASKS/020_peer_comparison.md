# Task 020 - 동종 업종·시장 비교

## 목표

종목 페이지에 PER, PBR, ROE, 영업이익률을 같은 업종, 같은 시장의 다른 종목과 비교하는 표를 추가한다.
값, 그룹 중앙값, 그룹 내 순위를 보여주며 좋고 나쁨은 판단하지 않는다.

## 구현 내용

- `analysis/peer_comparison.py` (순수 함수): 전 종목의 지표를 받아 종목별 비교 결과를 만든다.
- `automation/peer_info.py`: 종목별 지표와 기준 시점, 업종코드를 비교 입력으로 바꾸고, 결과를 리포트용
  `PeerGroup`/`PeerMetricRow`로 바꾼다. 업종 설명 문구도 여기서 만든다.
- `daily_update`: 비교에 전 종목의 지표가 필요해서 지표를 먼저 모두 계산한 뒤 페이지를 만드는 2단계로 바꿨다.
- 템플릿/필터: "동종 업종·시장 비교" 섹션 (페이지 맨 아래), 순위 표시 `fmt_rank`.

## 비교 규칙

- **업종 그룹:** DART 업종코드(KSIC)의 앞 3자리(소분류)가 같은 종목들이다. 소분류 종목이 10개 미만이면
  앞 2자리(중분류)로 넓히고, 그래도 10개 미만이면 업종 비교를 생략하고 시장 비교만 보여준다.
  업종코드가 3~5자리로 섞여 있어도 KSIC가 계층 구조라 앞자리 비교가 성립한다.
- **시장 그룹:** 같은 시장(KOSPI, KOSDAQ, KONEX) 종목들이다.
- **같은 기준 시점만 비교:** PER·PBR은 밸류에이션 기준 월, ROE·영업이익률은 재무제표 기준 연도가 같은 종목끼리만
  비교한다. 기준 시점이 다른 종목은 표본에서 빠지고, 그 종목 자신은 표본이 부족하면 `-`로 표시된다.
- **PER·PBR이 0 이하(적자 등)인 값은 중앙값과 순위에서 뺀다.** ROE·영업이익률은 음수도 포함한다.
- **표본 10개 미만이면** 중앙값과 순위를 표시하지 않는다.
- **순위는 값이 큰 순서**(1위가 가장 큼)이고 동률은 같은 순위다. PER·PBR은 작을수록 저평가라는 식의 해석을
  붙이지 않는다. 페이지에 "순위는 값이 큰 순서"라고 적는다.
- 업종 이름은 2자리 중분류의 것이라, 소분류 그룹은 "○○업 중 KSIC 264 동종"으로 표기한다.

## 확인 결과 (2026-10-11)

- `uv run pytest` 243개 통과 (순위·중앙값, 동률, 최소 표본, 제외 규칙, 기준 시점 불일치, 업종 그룹 확대,
  리포트 변환, 두 가지 표 형식, 파이프라인 테스트).
- 실제 데이터: 비교 섹션이 2,546개 페이지에 생겼다. 업종 그룹이 있는 페이지 2,466개, 시장 비교만 있는 페이지 80개.
- 예) 삼성전자: 업종 "KSIC 264 동종 66개", PER 33.95(업종 12위/31개), ROE 10.36%(업종 6위/57개).
- 2,831개 페이지를 `hugo` 빌드해 마크다운의 제목·표·차트 개수가 HTML과 일치하고
  외부 텍스트로 인한 shortcode/스크립트 유입이 없음을 확인했다.

## 알려진 제한

- 업종 구분이 DART 업종코드의 앞자리에 의존한다. 같은 소분류 안에서도 사업 성격이 다른 회사가 섞일 수 있다
  (예: 소분류 264는 가전 중심이지만 삼성전자의 주력은 반도체·모바일이다).
- 지표별로 비교 대상 종목 수가 다르다("12위 / 31개"). 적자 종목은 PER에서, 매출이 없는 종목은
  영업이익률에서 빠지기 때문이다.
- 재무제표가 연결/별도 혼재인 채로 비교한다.
- 백분위, 막대 그래프 같은 시각 표현은 넣지 않았다 (Task 021에서 다룰 수 있다).
