# Task 004 - 기본 시장 데이터 수집

## 목표

우선 하나의 안정적인 데이터 소스를 대상으로 종목 목록 수집기를 구현한다.

## 선행 조건

이전 Task가 완료되고 테스트가 통과한 상태여야 한다.

## 작업 범위

crawler/, tests/

## 수정 금지 원칙

현재 Task와 직접 관련 없는 영역은 수정하지 않는다.
구조 개선이 필요하더라도 먼저 이유를 보고하고 최소 변경으로 처리한다.

## 구현 요구사항

- 기존 프로젝트 규칙을 따른다.
- 타입 힌트를 사용한다.
- 핵심 로직에 테스트를 작성한다.
- 예외 상황을 명시적으로 처리한다.
- 로그가 필요한 경우 logging을 사용한다.
- 외부 API를 사용하는 경우 fixture/mock을 이용해 반복 가능한 테스트를 만든다.
- 비밀값을 코드나 테스트 fixture에 넣지 않는다.

## Acceptance Criteria

fixture 기반 파싱 테스트와 DB 저장 테스트가 통과해야 한다.

추가 Acceptance Criteria:
- 기존 테스트가 깨지지 않는다.
- Task 완료 후 로컬에서 기능을 직접 실행할 수 있다.
- 변경된 파일 목록이 명확하다.

- [ ] 필요한 문서 업데이트

- [ ] Git commit 가능한 상태
