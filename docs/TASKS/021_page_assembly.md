# Task 021 - 페이지 조립과 스타일

## 목표

종목 페이지의 섹션 순서를 정리하고, 목차와 스타일을 추가해 읽기 쉽게 만든다.

## 구현 내용

- 섹션 순서: 가격 차트 → 주요 지표 → 재무 시계열 → 주요 실적 요약 → 동종 업종·시장 비교 → 기업 개요.
  숫자와 차트가 먼저 보이고, 길이가 가변적인 기업 개요(사업 내용, 연혁)는 참고 자료로 맨 아래에 둔다.
- `stocks/single.html`: 2단계 제목(`##`) 기준 목차를 제목 아래에 표시한다 (`hugo.yaml`의 `tableOfContents`).
- `style.css`: 본문 폭 960px, 섹션 제목 구분선, 표 헤더 배경과 숫자 정렬, 넓은 표 가로 스크롤, 모바일 여백.

## 확인 결과 (2026-10-11)

- `uv run pytest` 243개 통과 (순서 검증 추가, 외부 텍스트 shortcode 검사는 기업 개요 섹션 기준으로 변경).
- `hugo` 빌드 후 목차가 렌더링되는 것을 확인했다.

## 알려진 제한

- 기존 `website/content/stocks/*.md`는 다시 생성하지 않았다. `daily_update`를 실행하면 새 순서로 바뀐다
  (전 종목 변경이므로 `chore: generate ...` 커밋으로 따로 반영한다).
