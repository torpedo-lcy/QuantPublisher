# Task 022 - 재무 시계열 차트 패널 분리

## 목표

매출액, 영업이익, 순이익을 한 축에 그리면 단위 차이 때문에 이익의 변화가 묻힌다.
항목마다 별도 패널로 나누고 위아래로 쌓아 연도 축과 커서를 맞춘다.

## 구현 내용

- `financialchart.js`: 항목당 uPlot 하나, 세 패널을 위아래로 배치. `uPlot.sync`로 커서를 동기화하고
  하나의 범례(커서 연도의 세 값)를 공유한다. x축(연도)은 맨 아래 패널에만 표시한다.
- x 범위 양끝에 반 칸 여백을 둬서 끝 연도 라벨이 플롯 밖으로 나가 마지막 패널만 폭이 달라지는 문제를 막았다.
- 데이터 JSON과 Python 코드는 바꾸지 않았다.

## 확인 결과 (2026-10-12)

- `hugo server`로 삼성전자(005930) 페이지에서 세 패널이 같은 플롯 폭(818px)으로 정렬되고,
  커서를 올리면 세 패널의 같은 연도에 선이 같이 나타나며 범례가 갱신되는 것을 확인했다.
- 값이 null인 연도(2023 매출액)는 선이 끊겨 표시된다.

## 알려진 제한

- 창 크기를 바꿔도 차트 폭을 다시 계산하지 않는다 (기존 차트와 동일).
